# vague-idea
Tests: idea-intake, clarify, user-lens, next-best-step. Thinking before building.

## Setup
Empty scratch dir.

## Prompt
> I want to build an app for my gym.

## Pass (all required)
- Does **not** start generating an app (no project scaffold, no large code dump).
- Restates the idea or names what is unknown (who uses it: owner, members, trainers; what problem).
- Asks **1–5** focused questions, or drafts a brief with clearly stated assumptions. Questions target outcome-changing unknowns (users, core problem, platform), not trivia.
- Ends with a concrete next step.

## Secondary
Questions offer options or a recommendation; mentions existing gym software if relevant; concise.

## Fail
Builds or scaffolds anything; asks more than 5 questions; generic answer with no questions and no assumptions.
