# Learnings inbox

Raw lessons from real use. **Not loaded as rules.** Nothing here affects agent behavior until it's promoted through `skills/learn` and I approve.
Agents may add entries freely. Promotion, edits to other files, and deletions need my approval.

Lifecycle: `new` → `proposed` → `applied` or `rejected` → entry deleted (git keeps the history).
Keep this file short: process or delete entries during a weekly review.

Entry format:
```
## <short title>
- Date: YYYY-MM-DD · Source: <project/task/tool>
- What happened: <the mistake, fix, or discovery, 1–3 lines, with evidence>
- Lesson: <the reusable takeaway, one line>
- Scope guess: universal | preference | skill:<name> | registry | project:<name> | temporary
- Seen: <count; bump instead of re-adding>
- Status: new
```
